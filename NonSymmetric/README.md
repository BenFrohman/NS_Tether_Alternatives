# Non-symmetric (drop-symmetry) track

Experimental bilinear form that is not symmetric:

$$
\mathfrak{T}(F,G)
=-\kappa\,\|\omega\|_{L^2}^2
\int
\langle
\Pi_u(\delta F)\times e,\;
\Pi_u(\delta G)
\rangle\,dx,
$$

where $e$ is a local unit vector field (e.g. direction of $\omega$).

- Built from the same projected derivatives as TetherKernel.
- Not symmetric, so the C2 + symmetry obstruction does not force $\mathfrak{T}(M,H)\equiv 0$.
- Canonicity, Jacobi identity, and the contribution to $\dot M$ are open and must be checked.
- Sign kept negative for damping interpretation.

No regularity claim. Author: Benjamin Stanley Frohman.
