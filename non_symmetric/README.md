# Non-symmetric candidate (experimental)

A concrete bilinear (but not symmetric) form that is still built from the projected derivatives:

$$
\mathfrak{T}(F,G)
  =-\kappa\,\|\omega\|_{L^2}^2
    \int
      \langle
        \Pi_u(\delta F)\times e,\;
        \Pi_u(\delta G)
      \rangle\,dx,
$$

where $e$ is a local unit vector field (for example the direction of $\omega$, not of $u$).

## Algebraic properties
- Bilinear in $(\delta F,\delta G)$.
- Not symmetric in general.
- No longer a metric correction.
- Can be arranged so that the first slot vanishes on the kinetic-energy derivative (C2 / energy conservation) while the pairing against a Lyapunov functional need not vanish.

## Status
This is a candidate repair for the C2/C3 obstruction. It requires a new canonicity argument and a quantitative lower bound (projection gap remains). No regularity claim is made.
